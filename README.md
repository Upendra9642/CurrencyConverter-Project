# 💱 CurrencyConverter-Project

A simple and responsive **Currency Converter** web application built using **HTML**, **CSS**, and **JavaScript**. It converts currencies using real-time exchange rates from an Exchange Rate API, providing accurate and up-to-date conversion results. :contentReference[oaicite:0]{index=0}

## 🚀 Live Demo

🔗 https://upendra9642.github.io/CurrencyConverter-Project/

## ✨ Features

- 💱 Convert between multiple currencies
- 🌍 Supports various international currencies
- 📈 Real-time exchange rates
- 🔄 Instant currency conversion
- 📱 Responsive and user-friendly interface

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Fetch API)
- Exchange Rate API

## ▶️ How to Use

1. Open the Live Demo.
2. Enter the amount to convert.
3. Select the source and target currencies.
4. Click the **Convert** button.
5. View the converted amount instantly.
